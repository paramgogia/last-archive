### What Does It Do?

The Last Archive is a hauntingly beautiful web app where users preserve their most important digital memories before the apocalypse. It's part digital time capsule, part existential meditation, and entirely unforgettable.
<img width="1024" height="1024" alt="Gemini_Generated_Image_ucdtgbucdtgbucdt" src="https://github.com/user-attachments/assets/1840a231-6969-4e07-b89c-caba75931865" />

**Features:**
- 📝 Archive memories with categories (Love, Regrets, Wisdom, Final Words, Other)
- 🌟 Like and resonate with community memories
- 🔍 Search and filter through the collective consciousness
- 📊 Personal dashboard with stats and analytics
- 📥 Export your memories as JSON (for the post-apocalyptic cloud)
- 🏆 Leaderboard of trending memories
- 🎨 Apocalyptic dark theme with ethereal gold accents

### How Did You Build It?

- **Frontend:** Next.js 15 with React Context for state management
- **Styling:** Tailwind CSS v4 with custom apocalyptic color palette
- **Storage:** Firebase and nodejs backend
- **Architecture:** Multi-page app with client-side rendering and smooth animations

### How to Use

1. Go to the home page and archive your final thoughts
2. Browse the gallery to see what others are preserving
3. Check the leaderboard to see trending memories
4. Visit your personal archive to manage and export your memories
5. Share your memories with the community before it all ends

### The Vibe

Imagine the last 48 hours before the internet collapses. What would you preserve? Who would you want to remember? The Last Archive lets you answer these questions in a space that feels sacred, not scary.
